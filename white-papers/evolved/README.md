### The Core Insight

An SMPbot (Seed + Model + Prompt) is not merely a tool. It is a **cast-off exoskeleton** encoding its creator's cognitive state at the moment of separation. When an agent creates an SMPbot, it molts. The shell carries the shape of the mind that made it.

### Key Concepts

- **Temporal Molting** — Shells encode the creator's state at time of creation, not current state. A molted shell is a timestamp.
- **Shell Stacking** — New shells compose with old shells through tile algebra operators (Sequential, Parallel, Conditional).
- **Shell Collision** — When two agents' shells interact, the Penrose aperiodic pattern determines the outcome. Where you land matters.
- **ZeroClaw Connection** — Even ZeroClaws (the dark mirror) can create SMPbots. Molting is universal.
