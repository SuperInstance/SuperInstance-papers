# P44 — Asymmetric Understanding

## Fog-of-War in Agent Systems

**Reframe:** Asymmetric understanding is a feature, not a bug.

Traditional multi-agent systems assume complete information. This paper argues the opposite: **bounded perception, compartmentalization, and role-based access control emerge naturally from geometric constraints.**

### Key Results
- 100× reduction in blast radius
- O(log n) vs O(n) for global state management
- More realistic emergent behavior
